# data/

| Path | Content | In git |
|---|---|---|
| `demo/catalog.json` | Manifest of the 48 original demo songs (metadata, generator parameters, sections) | generated by `make demo-data` |
| `demo/midi/*.mid` | Reference melodies (original, CC0) | generated |
| `demo/lyrics/*.json` | Original lyrics for 20 songs (CC0) | generated |
| `demo/audio/*.wav` | Piano renderings for listening (22.05 kHz) | ignored (regenerable, ~90 MB) |
| `demo/checksums.json` | SHA-256 of every MIDI file, to verify reproducibility | generated |
| `store/` | Your local catalog: SQLite DB, features, media, indexes, settings | ignored (private) |
| `metadata/` | Example manifest for bulk imports | yes |

The demo catalog is regenerated deterministically from seeds (`melodyai/demo/generator.py`,
base seed 1000). Running `make demo-data` twice yields identical MIDI checksums.

No third-party dataset is stored here. See `docs/DATASETS.md` for research datasets and their
licences; download them yourself and import them with `melodyai import-dir` or the web UI only if
their terms allow your use.
